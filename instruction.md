# Инструкция: перевод считывателя КСУ на нужный формат пропусков

**Что делаем:** меняем в считывателе строку, по которой он печатает номер карты,
чтобы пропуск читался в формате нашей системы.

| | Номер карты |
|---|---|
| **Как печатается сейчас** | `048061C2DA3E58` |
| **Как должно быть** | `8061C2DA3E5804` |

Меняется только порядок байтов: первый байт `04` переезжает в конец.
Всё остальное в считывателе (серийник, автоповтор, флаги) не меняется.

Для этого в считыватель записывается готовая строка:

```
%50U%40U%30U%20U%10U%00U%60U
```

---

## 1. Что понадобится

* Компьютер с Windows (программа работает без установки и без прав администратора).
* Считыватель КСУ, один — не подключайте сразу несколько.
* Пропуск (карта), на которой будем проверять результат.
* Тонкая отвёртка, чтобы снять корпус считывателя.
* Программа `KsuConfigurator.exe` — лежит в папке `KsuConfigurator\bin`.

---

## 2. Подготовка считывателя

1. Отключите считыватель от компьютера.
2. Вскройте корпус и **снимите все перемычки (джамперы)**.
   В режиме, которым управляет программа, перемычек быть не должно — иначе
   считыватель работает по «железной» настройке и программа его не увидит.
3. Соберите корпус, подключите считыватель к компьютеру.
4. Убедитесь, что к компьютеру подключён **только один** считыватель КСУ.

---

## 3. Чтение текущих настроек (обязательно)

1. Запустите `KsuConfigurator.exe`.
2. Программа сама найдёт считыватель при запуске.
   Если список пуст — нажмите **«Найти считыватели»**.
3. В таблице должна появиться строка с пометкой **«свой»**, например
   `RFID Reader / PROX (www.prox.ru)` с `VID:PID 046E:52C3`.
   Строки с пометкой `[CreateFile: Отказано в доступе]` — это клавиатура и другие
   системные устройства, они не наши, их не трогаем.
4. Нажмите **«Прочитать из устройства»**.
   Поля заполнятся тем, что сейчас записано в считывателе.
5. **Перепишите или сделайте фото текущей строки формата** — это ваш способ
   вернуть всё назад, если понадобится.
6. Проверьте, что в поле «Версия прошивки» стоит не `0.0` — значит, связь есть
   и параметры прочитаны.

---

## 4. Запись новой строки

1. Очистите поле **«Строка формата вывода»** и вставьте:

   ```
   %50U%40U%30U%20U%10U%00U%60U
   ```

2. Под полем должен появиться счётчик примерно `28 / 112` — это нормально.
   Если вместо счётчика появилось сообщение с красным текстом на «ошибка» —
   строка вставлена с искажением (например, вместо `%` попал другой символ),
   повторите вставку.
3. Если хотите, чтобы строка осталась в списке заготовок — нажмите
   **«Добавить в [FStrings]»**. На саму запись это не влияет.
4. Нажмите **«Записать в устройство»**.
5. Откроется окно подтверждения с полным дампом того, что уйдёт в считыватель.
   Проверьте: с начала второй строки должно идти
   `25 35 30 55 25 34 30 55 25 33 30 55 …` — это и есть наша строка в байтах.
6. Нажмите **«Записать»**.
7. В логе появится «Записано. Перечитываю для контроля», а поля заполнятся
   прочитанным из считывателя. Строка формата должна остаться той, что вы вставили.

> Если окно «не отвечает» и кнопки не нажимаются — не нажимайте «Записать»
> повторно. Скорее всего, включено «Слушать отчёты»; подождите несколько секунд.
> В текущей версии программы прослушивание останавливается автоматически перед
> чтением и записью, и в лог пишется «Слушание остановлено перед записью».

---

## 5. Проверка

1. Откройте Блокнот (или любое поле ввода) и поставьте в него курсор.
2. Поднесите пропуск к считывателю.
3. Должно напечататься:

   ```
   8061C2DA3E5804
   ```

4. Отдельно проверьте в программе: **«Прочитать из устройства»** — строка формата
   должна вернуться из считывателя целиком, без обрезания.

Если напечаталось другое — не записывайте ничего повторно, а пришлите
фактически напечатанную строку: порядок байтов подбирается по факту, а не наугад.

---

## 6. Если нужно вернуть как было

1. «Прочитать из устройства».
2. Вставьте в поле формата строку, которую вы сохранили на шаге 3.5.
3. «Записать в устройство» → «Записать».

---

## 7. Частые вопросы

**Считыватель не появился в списке.**
Проверьте, что сняты перемычки, подключён только один считыватель и он подключён
к этому компьютеру. Нажмите «Найти считыватели» ещё раз.

**В таблице несколько строк с «Отказано в доступе».**
Это нормально: так помечены интерфейсы обычной клавиатуры и служебные коллекции
устройства. Работаем только со строкой, у которой признак «свой».

**В окне подтверждения «версия 0.0».**
Так и должно быть: поле версии при записи не заполняется (так же ведёт себя
и оригинальная программа). После записи чтение снова покажет реальную версию.

**На клавиатуре вместо букв печатаются русские символы.**
В номере есть латинские буквы `C`, `D`, `E`, `A`. При выводе «как клавиатура»
они зависят от раскладки — переключите её на английскую. На систему, которая
читает считыватель как USB HID-устройство, это не влияет.

**Можно ли записывать много раз?**
Параметры хранятся во flash-памяти с ресурсом «несколько десятков тысяч
перезаписей». Смена формата — это одна запись; не гоняйте её по кругу
ради эксперимента, проверяйте результат поднесением карты.

**Подходит ли эта строка для всех карт?**
Строка рассчитана на карты с 7-байтовым UID (номер начинается с `04`).
Для карт с другим UID порядок вывода будет другим — для них нужна своя строка.
